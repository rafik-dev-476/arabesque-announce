# Announcement Studio

Build a Discord announcement bot dashboard in Arabic. It should let an admin compose an embed-style announcement with title, body text, image/banner, color, button label and link, preview it in a Discord-like card, and publish it via a Discord slash command such as /announce where the admin selects prepared content and an optional target channel. Include clear setup instructions for connecting a Discord bot and required permissions. Use Lovable Cloud for saving announcement templates and uploaded images, with admin access suitable for a single owner.

This project was built with [Lovable](https://lovable.dev).
